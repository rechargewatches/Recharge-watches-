# Recharge Watches

Watch store — static site on GitHub Pages, backend on Supabase.

- `index.html` — storefront (products, discounts, cart, cash-on-delivery checkout)
- `admin.html` — admin: sales dashboard, orders (live), products/images/discounts, settings
- `assets/config.js` — Supabase URL + publishable key (data protected by RLS)
